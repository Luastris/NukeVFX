# NukeVFX

The particle/VFX module for [NukeEngine](https://github.com/Luastris/NukeEngine-Eco):
CPU simulation on the engine's job pool, rendered through the neutral sprite/instancing
seams — a separate module by design, so games without effects never pay for it. An EFFECT
is a regular prefab whose atoms carry `ParticleEmitter` components: standard inspector,
undo, serialization, and mod diffs — no side formats.

## Features

- **Emission** — rate + periodic bursts, shapes Point / Sphere / Box / Cone /
  MeshSurface (volume or shell), initial life/speed/size/rotation ranges, velocity
  inheritance, local-space simulation.
- **Forces** — gravity, drag, the global `nuke::Wind` field (zones, gusts, turbulence),
  and `ForceField` volumes (Attract / Repel / Vortex / Turbulence).
- **Rendering** — Billboard / velocity-Stretched / Mesh (GPU instancing) base modes, plus
  a **Trail** ribbon option on top of any of them: continuous UV along the ribbon, its
  own texture, width/taper/fade controls. Built-in procedural particle shapes
  (Circle / Ring / Spark / Star / Smoke) when no texture is assigned. Alpha/additive
  blending, optional back-to-front sorting, soft particles near scene geometry.
- **Curves & gradients** — size/alpha over lifetime as Bezier curves (per-key tangent
  handles in the inspector), color over lifetime as a gradient bar editor.
- **Collision** — honest surfaces only: `World` (physics rays in play, scene-mesh rays in
  the editor preview) or `Surface` (exact ray-vs-triangle against one referenced atom's
  meshes — no colliders needed). Bounce/dampen/die-on-hit, budgeted per frame
  (round-robin with tunnel-proof reach). Optional `vfx.collision` events with the hit
  point, normal, atom, and UV.
- **Sub-emitters** — burst another emitter where particles die or collide.
- **Scripting** — `Play / Stop / Clear / Burst / BurstAt / AliveCount` reflected to C++,
  Lua, and C# like every engine component.

```lua
local e = atom:getComponent("ParticleEmitter")
e:BurstAt(nuke.Vector3(x, y, z), 50)
```

## Building

Part of the [NukeEngine-Eco](https://github.com/Luastris/NukeEngine-Eco) superbuild, or
standalone: `cmake -S . -B build -G "Visual Studio 17 2022" -A x64` +
`cmake --build build --config Debug` (needs `VCPKG_ROOT`; engine first). The build copies
`NukeVFX.dll` into the runtime `modules/` folder; reflection code is generated by the
nukegen prebuild from `include/NukeVFX/Particles.h`.
